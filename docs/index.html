Pascal OpenCV

Use OpenCV 4.10.0 from Object Pascal to resize and transform images, manage native image buffers, and read and write video.

At a glance

Pascal binding units25
Windowsx64
CompilersDelphi 13.2 and Lazarus 4.8

Try the examples

  1. Build bin/crosscv.dll using the native source guide.
  2. Open examples/CrossCVHello.dproj or examples/CrossCVHello.lpi. Build for Windows x64 and run.
  3. Open the corresponding LoadResizeSave project to choose an image and save a 640 × 480 PNG.

See the installation guide for details.

Verified on Windows x64

The two Pascal examples ran in Delphi and Lazarus. CrossCVHello reported a pixel sum of 84 and 12 nonzero pixels. LoadResizeSave saved identical PNGs across both compilers.
